# Contact Book

A command-line contact management program built with Python. It allows users to store, search, display, add, and delete contact information.

## Features

- Register multiple contacts
- Store names and phone numbers
- Display all saved contacts
- Search for contacts by name
- Add new contacts
- Delete existing contacts
- Validate phone number input
- Prevent duplicate contact names
- Exit through a menu-driven interface

## Concepts Practiced

- Functions and return values
- Dictionaries and nested data structures
- Loops and conditional statements
- User input and validation
- Searching, adding, and deleting records
- Handling duplicate entries
